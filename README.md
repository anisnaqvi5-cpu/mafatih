# مفاتیح PWA — محتوا کیسے شامل کریں

## فولڈر کی ترتیب
```
index.html          اپ (ایک ہی فائل)
manifest.json       install کی معلومات
sw.js               offline cache
data/index.json     خودکار بنتا ہے — ہاتھ سے نہ بدلیں
data/items/*.json   ہر دعا/زیارت کی الگ فائل  ← یہاں محتوا ڈالیں
audio/*.mp3         صوت فائلیں
build/add.html      متن سے JSON بنانے کا اوزار
build/build.py      index.json دوبارہ بنانے کا script
```

## نیا متن شامل کرنے کے ۳ قدم
1. `build/add.html` براؤزر میں کھولیں، عربی + اردو paste کریں، **Download file** دبائیں۔
2. فائل کو `data/items/` میں رکھیں۔
3. `python3 build/build.py` چلائیں — یہ index.json بناتا اور غلطیاں بتاتا ہے۔

نئی category چاہیے تو `build/build.py` میں `CATEGORIES` کی فہرست میں اضافہ کریں۔

## ہر item کی شکل
```json
{
 "id": "kumayl",          فائل کے نام جیسا ہونا لازم ہے
 "cat": "adiya",
 "ur": "دعائے کمیل",
 "en": "Dua Kumayl",
 "when": "شب جمعہ",
 "group": "rajab",              اعمال کے لیے: کس قمری مہینے سے تعلق ہے
 "hijri": [ { "m": 7, "d": 13 } ],   کس تاریخ کو "آج کے اعمال" میں دکھایا جائے
 "audio": [
   { "reciter": "میثم مطیعی", "file": "audio/kumayl-1.mp3" },
   { "reciter": "فرہاد",      "file": "audio/kumayl-2.mp3" }
 ],
 "lines": [ { "ar": "…", "ur": "…" } ]
}
```
`lines` کو سطر بہ سطر رکھیں — اسی سے Focus mode، ترجمہ on/off اور آگے چل کر صوت کی ہم‌آہنگی ممکن ہوتی ہے۔

## چلانے کا طریقہ
```
python3 -m http.server 8000
```
پھر `http://localhost:8000`

## Word یا EPUB سے انبوہ import
```
python3 build/import_docx_epub.py mafatih.docx --cat adiya --dry
```
`--dry` صرف دکھاتا ہے کہ کیا بنے گا (کچھ save نہیں ہوتا)۔ نتیجہ درست لگے تو `--dry` ہٹا دیں، پھر `python3 build/build.py` چلائیں۔

script یہ فرض کرتا ہے:
- **bold یا heading** والی سطر = نئی دعا کا عنوان
- **عربی سطر** = "ar" ، اُس کے فوراً بعد کی **اردو سطر** = اُسی لائن کا ترجمہ

اگر آپ کی فائل میں عنوان bold نہیں (مثلاً صرف بڑا فونٹ یا رنگ) تو ID غلط بنیں گے — ایسی صورت میں فائل کا ایک نمونہ بھیجیں، script کا قاعدہ اُسی کے مطابق بدل دیا جائے گا۔

## اعمال کی ترتیب
`cat: "amaal"` والے متون مہینوں کے فولڈر میں دکھائے جاتے ہیں۔ اس کے لیے دو فیلڈ ہیں:
- `group` — مہینے کی id: muharram, safar, rabi1, rabi2, jumada1, jumada2, rajab, shaban, ramadan, shawwal, dhulqada, dhulhijja
- `hijri` — مخصوص دن، مثلاً `[{"m":9,"d":21}]`۔ یہی فہرست **آج کے اعمال** والے صفحے کو چلاتی ہے۔

ایک عمل ایک سے زیادہ دنوں کا ہو سکتا ہے: `[{"m":9,"d":19},{"m":9,"d":21}]`۔

## خودکار حرکتِ متن (Auto-scroll)
صفحهٔ متن میں ⬇ دکمہ ظاہر ہے (جب صوت موجود ہو)۔ اسے دبانے سے:
- متن خود‌بہ‌خود نیچے کی طرف حرکت کرتا ہے
- رفتار کو ۱۰ سے ۱۰۰ فیصد تک کنٹرول کریں (Settings یا نوار کے ذریعے)
- جب صوت play ہو تو scroll شروع ہو، pause ہو تو رک جائے (sync)
- ترتیب محفوظ ہوتی ہے — اگلی بار وہی رفتار رہے گی

یہ خاص طور پر طویل زیارات یا نمازوں کے لیے مفید ہے جب صوت کے ساتھ پڑھ رہے ہوں۔

## Search Results (نتائجِ تلاش)
جب کوئی لفظ لکھیں تو نتائج تاریخ کے مطابق group ہوتے ہیں (ادعیہ، زیارات، اعمال، نمازیں)۔ ہر group کے بغل میں عدد ہے۔ ▼ دبانے سے group collapse ہو جاتا ہے۔


## Search Intelligence (ذہین تلاش)
سرچ خود سمجھتا ہے کہ کیا لکھا گیا:

**اردو یا فارسی لفظ:** عنوان + **ترجمے کی سطروں** میں تلاش
- مثال: "دعاء" یا "کمیل" لکھیں

**عربی متن:** **عربی سطروں** میں تلاش
- مثال: "اللهم" یا "إِنِّي" لکھیں

**English:** عنوان میں (case-insensitive)
- مثال: "dua" یا "imam" لکھیں

**فائدہ:** اب جب اردو میں "دعا" لکھو تو عربی "دعاء" والے نتائج آتے ہیں۔ اور عربی میں "اللهم" لکھو تو اردو ترجمے والی متابقت ہو۔


## Advanced Display Settings (متقدمہ نمائش)
Settings میں اب یہ اختیارات ہیں:

**۱. سطروں کا فاصلہ (Line Spacing)**
- قریب (1.8x): الفاظ میں پڑھتے وقت
- معمول (2.1x): عام خواندگی
- کشادہ (2.6x): دیر تک پڑھنے کے لیے

**۲. رنگ (Theme)**
- عام: سفید پس‌منظر
- سپیا: پرانا کاغذ (گرم بھوری)
- گرم: ہلکا کریم (آنکھوں کے لیے نرم)

**۳. صوت کی رفتار (Playback Speed)**
پخش‌کننده میں **1x** دبانے سے:
- 0.75x (آہستہ)
- 1x (معمول)
- 1.25x
- 1.5x
- 2x (تیز)

ہر تبدیلی فوری اثر ڈالتی ہے — آڈیو روکنے کی ضرورت نہیں۔


## Repeat Counter & Audio EQ (دوہرانے کی شمار اور صوت کی معیار)

**۱. Repeat Counter (کتنی بار سنی)**
- جب دعا **repeat mode** میں ہو (▼ repeat on)، ہر بار جب ختم ہو تو شمار بڑھ جاتی ہے
- **1 ×** سے شروع ہو کر: **2 ×, 3 ×** وغیرہ
- محفوظ رہتی ہے — اگر اپ بند کریں تو اگلی بار وہی گنتی سے شروع ہو

**۲. Audio EQ (صوت کے نمونے)**
پخش‌کننده میں **EQ** دبانے سے چار preset:
- **عام** — اصل آواز
- **بھرپور** — زیادہ bass + treble (منظوری والی دعائیں)
- **صاف** — کم bass، زیادہ treble (وضاحت والی)
- **گرم** — زیادہ bass (گہری دعائیں)

فی الوقت یہ **presets** ہیں۔ اگر حقیقی EQ sliders چاہیں (bass/treble کنٹرول) تو Web Audio API استعمال کرنا پڑے گا — زیادہ پیچیدہ ہے۔

## Repeat Limit (خود‌کار لوپ کی تعداد)

**کیسے کام کرتا ہے:**
۱. **Repeat mode ON** کریں (▼ repeat)
۲. **Repeat bar** میں number field ظاہر ہے
۳ عدد درج کریں: **۱, ۲, ۳** وغیرہ (یا +/− بٹن استعمال کریں)
۴. **Play** دبائیں → صوت اتنی بار خود‌بہ‌خود بجے گی، پھر **رک جائے گی**

**مثال:**
- Repeat limit = ۳
- صوت بجتی ہے، ختم ہوتی ہے → دوبارہ شروع
- دوسری بار ختم → دوبارہ شروع  
- تیسری بار ختم → **رک جاتی ہے** ✓

**Counter:**
- ہر بار کے لیے شمار برقرار ہے (۱ ×، ۲ ×، ۳ ×)
- اگر دوبارہ کریں تو ۴ × سے شروع

**خالی رکھیں = لامحدود:**
اگر number field خالی ہو تو عام repeat mode (جب تک manual روکو)
